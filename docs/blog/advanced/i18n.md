# 多语言支持

> Zensical 站点的语言设置与多语言内容组织方式

## 设置界面语言

在 `zensical.toml` 中设置站点语言：

```toml
[project.theme]
language = "zh"
```

这会切换主题内置文案（搜索、目录、上一篇/下一篇等）的语言。常用值包括 `zh`、`en`、`ja` 等。

## 语言切换入口

主题支持通过 `extra.alternate` 显示语言切换菜单：

```toml
[[project.extra.alternate]]
name = "中文"
link = "/"
lang = "zh"

[[project.extra.alternate]]
name = "English"
link = "/en/"
lang = "en"
```

注意：`alternate` 只负责渲染切换入口，不会自动翻译内容。

## 多语言内容的组织方式

Zensical 目前没有像某些 CMS 一样的内置内容翻译工作流，常见做法有两种：

1. **按目录拆分**：中文放在 `docs/`，英文放在 `docs/en/`，分别构建或通过导航切换
2. **独立站点**：中英文各维护一个仓库或构建目标，通过自定义域名或子路径发布

如果只是希望浏览器把页面翻译成其他语言，可以使用浏览器自带的翻译功能，不需要修改站点结构。

## 注意事项

- 不同语言页面应使用各自的 `site_description` 和导航
- 翻译后的页面需要单独维护，避免中英文内容长期不同步
- 如果使用 `/en/` 子路径，记得同步配置 `site_url` 和 sitemap
